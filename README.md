# 小分贝仪 · DecibelMeter

一款 iOS 实时环境噪音检测 App。打开即测，把「吵不吵」变成看得见的数字，并把一段时间内的噪音情况整理成可留存的测量结果。

App Store 下载：<https://apps.apple.com/app/id6819623115>

> 当前状态：海外区已上线（v1.1.1，2026.10），中国大陆区备案中。

---

## 关于产品

噪音困扰往往缺一个可参照的依据：楼上开始砸东西、舍友开始外放、隔壁装修从早到晚——想沟通，却拿不出「到底多吵、吵了多久」。

小分贝仪做的事很简单：**实时给出当前环境声级，并按场景判断是否超标；需要时把一段时间内的测量结果完整记录下来**，用于自己判断或与人沟通。

目标用户：宿舍学生、租房用户、需要评估居住或办公环境噪音的人。

## 核心特性

| 能力 | 说明 |
| --- | --- |
| 零操作启动 | 没有开始/停止按钮，打开即测，离开自动停止 |
| 实时声级 | 毫秒级刷新的分贝读数与刻度盘，8 点滑动平均保证可读性 |
| 场景阈值 | 卧室、书房、客厅、办公、交通、广场舞、装修 7 类场景，各带安全线与红线 |
| 定时测量 | 按设定时长连续采集，输出等效连续声级（Leq）、峰值与超标时长 |
| 测量报告 | 生成可保存的测量卡片，支持导出图片与 CSV |
| 历史记录 | 本地保存每次测量结果，可单条删除 |

## 技术实现（简述）

- **采集**：`AVAudioEngine` 输入节点 `installTap` 直接读取 PCM buffer，不经过录音文件
- **换算**：RMS → `dBFS = 20·log10(rms)` → 加校准偏移得到近似声压级；`log10(0)` 边界做钳位
- **统计**：显示值走滑动平均（求稳），统计值用原始采样（求真），两路分离
- **判定**：实时判定用瞬时值反映打扰感，报告判定用 Leq 反映能量暴露量
- **存储**：SwiftData 本地库，不上传、不同步
- **平台**：iOS 17+ / Swift / SwiftUI，适配 iPhone 与 iPad

## 隐私

- **不录音**：音频数据仅在内存中实时计算，不写入磁盘
- **不上传**：无账号体系、无服务端、无网络请求
- **只存数值**：历史记录只保存分贝数值与时间，不含任何音频内容
- **可删除**：任意一条历史记录都可单独删除

---

## 测量精度声明

本 App 使用手机麦克风测量环境音量，结果为相对参考值，未经专业校准。

- 可用于：观察噪音的相对变化与长期趋势
- 不可用于：法律举证、医疗诊断、工业计量或听力防护决策等需要精确计量的场景

不同机型麦克风灵敏度存在差异，实际偏差可能达数分贝。
